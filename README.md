## 上傳 GitHub Pages

1. 解壓後，把**資料夾內所有檔案**上傳到 repo **根目錄**
2. Settings → Pages → Deploy from a branch → `main` + `/ (root)`
3. 網址：`https://你的帳號.github.io/你的repo名/`

已含 `.nojekyll`。
